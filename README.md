- 安全区显示
- 相册/文件导入图片

- 图片、文字、按钮、面板四种元素
- 单指拖动元素、控制点缩放

- 实时参考线
- 多选、框选、整体移动、对齐、等间距

## v0.4.0 新增

### 全局素材库

导入的图片会登记进工程级素材目录。素材不再只依附当前页面，可从“资源库”在任意页面重复插入，同一个图片文件无需重复复制。

### 组件系统

可把当前一个或多个选中元素保存为组件。组件记录元素相对位置、样式、图片引用和尺寸；插入组件时会在画布中央生成新的独立实例，并自动作为一组管理。

### 页面模板

可把当前页面保存为页面模板，再从模板直接生成新页面。生成时会重建元素 ID 与分组 ID，避免与原页面冲突。

### 组内编辑

普通状态下点击组合中的任意元素仍会整体选中。进入“编辑组内”后，可单独选择、移动和调整组内元素；退出后重新恢复整组选择逻辑。

### 画布导航模式

新增“画布手势”模式。打开后暂停元素编辑，允许拖动画布并通过双指手势缩放画布，避免画布平移手势和元素拖动手势互相抢占。

## 工程格式

v0.4.0 工程格式升级为 `version = 3`，核心结构包括：

- `pages`：页面
- `assetLibrary`：全局素材索引
- `components`：可复用组件
- `pageTemplates`：页面模板
- `currentPageId`：当前页面

旧版 v0.1 / v0.2 的单页面 `elements` 仍会自动迁移；v0.3 的 `pages` 工程也可继续读取。

## 设计原则

设计坐标固定使用 1920×1080。设备预览尺寸不直接修改原始坐标，而是通过锚点和尺寸模式解析布局。

图片文件统一保存在工程 `assets/` 下，JSON 只保存路径和编辑参数，不保存 Base64。组件与页面模板复用同一套素材引用。

## 构建

GitHub Actions 已配置 `.github/workflows/android-build.yml`。推送到 `main` 后会构建：

`app/build/outputs/apk/debug/app-debug.apk`

也可以在 Android Studio 中直接打开根目录运行。
